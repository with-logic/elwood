# Elwood PRD

Status: Draft placeholder

This document is the product contract for Elwood. Observable behavior belongs
here before it belongs in code.

## 0. Spec Discipline

- `PRD.md` is the source of truth for externally observable behavior.
- Code is a derived artifact from the spec.
- Tests prove that the implementation conforms to the spec.
- A behavior change is complete only when the PRD, implementation, and tests
  agree in the same change.

## 1. Product Definition

To be written collaboratively.

## 2. Conformance Criteria

Every product requirement should eventually have a stable criterion ID, such as
`C-EXAMPLE-01`, with matching tests that name the criterion in the test title.
